# DROPIA

Herramientas con IA para creadores de contenido: menos horas editando, más videos publicados.

## Proyectos

**[DROPIA Clips](https://github.com/alanmiron966-prog/dropia-clips)**: pega el enlace de un directo de Twitch o de un video de YouTube y la app encuentra los mejores momentos (por el chat, lo más visto o lo más ruidoso) y los monta en vertical con subtítulos, listos para Shorts y TikTok.
[Descargar para Windows](https://github.com/alanmiron966-prog/dropia-clips/releases/latest)

**[DROPIA Instagram Agent](https://github.com/alanmiron966-prog/dropia-instagram-agent)**: agente que responde los mensajes directos de Instagram con IA, hace seguimiento de clientes potenciales y funciona en Cloudflare Workers.

## Con qué trabajo

Python · TypeScript · FFmpeg · Whisper · YouTube Data API · Meta Graph API · Cloudflare Workers · Claude
